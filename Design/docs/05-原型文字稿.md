## P01 · 启动页 Splash

- **布局**：全屏，居中
- **模块**：
  1. 中央 Logo "TideTune"（品牌字 32sp 600，渐变描边或填充）
  2. Logo 下方 12dp 间距，副标语 "潮汐流动，乐在其中" 12sp 灰
  3. 底部 32dp 间距，加载进度条 2dp 渐变（80dp 宽）
- **文案**：标语 = "潮汐流动，乐在其中"
- **交互**：1.2s 后自动进入 Home，不可手动跳过
- **状态**：仅一种状态
- **背景**：白主题纯白；夜主题 `#0B0B0F`，Logo 微发光

## P02 · 首页推荐 Home

- **布局**：顶部大标题 + 滚动列表
- **模块**（自上而下）：
  1. **顶部头部**（不需 TopAppBar）
     - 左：Logo "TideTune" 22sp 600
     - 右：主题切换图标 24dp
  2. **轮播横幅** BannerCarousel
     - 高 140dp，圆角 20dp，左右各留 16dp
     - 3-5 张运营位，4s 自动切换
     - 底部圆点指示器
  3. **每日推荐** DailyRecommendCard
     - 横向卡片，高 96dp，圆角 16dp
     - 左封面 72dp + 右文案 "今日推荐 · 30 首" + 渐变播放键
     - 右上角日期徽章 "06.24"
  4. **区块标题** "推荐歌单" + 更多 →
  5. **歌单网格** PlaylistCardGrid 2 列
     - 每张封面 1:1，圆角 20dp，下接歌单名 2 行 + 播放数
     - 默认 6 张，下拉加载更多
  6. **区块标题** "新歌速递" + 更多 →
  7. **新歌列表** 3 条 TrackRow
  8. **区块标题** "热门歌手" + 更多 →
  9. **歌手横向卡** 横向滚动，圆形头像 80dp + 名字
  10. **区块标题** "排行榜" + 更多 →
  11. **榜单卡** 横向滚动 3 张（飙升/新歌/热歌），每张含封面 + Top 3 歌名
- **文案**：区块名 = 推荐歌单 / 新歌速递 / 热门歌手 / 排行榜
- **交互**：
  - 顶部下拉 → 刷新（顶部出现 24dp 渐变 spinner）
  - 底部上拉 → 加载更多（底部 32dp 灰色 spinner）
  - 点歌单 → PlaylistDetail
  - 点曲目 → 触发播放，MiniPlayer 出现
  - 点歌手头像 → ArtistDetail
  - 点主题图标 → 弹出主题切换 Sheet
- **状态**：默认 / 下拉刷新 / 加载更多 / 空（无网络）

## P04 · 歌单详情 PlaylistDetail

- **布局**：英雄头部 + 工具行 + 曲目列表
- **模块**：
  1. **PlaylistHero** 英雄头部
     - 背景：封面虚化 30px + 70% 暗化遮罩
     - 左封面 120dp 圆角 20dp
     - 右：歌单名 title1 2 行 / 创建者头像 24dp + 昵称 / 标签 chips / 播放量
     - 底部按钮组：`[▶ 播放全部]`（渐变胶囊 48dp）+ `[♥ 收藏]`（描边）+ `[⬇ 下载]`（描边）
  2. **TopAppBar** 滚动后浮现，磨砂态，左返回 + 右分享 ⋯
  3. **工具行** `[播放全部] [下载全部] [排序 ↓]`，高 48dp
  4. **TrackList** 曲目列表
     - 行高 56dp，TrackRow × N
     - 左封面 40dp / 歌名 / 歌手·专辑 / 时长 / ⋯
     - 当前播放行歌名变品牌色 + 跳动音波图标
  5. **底部留白** 80dp（避让 MiniPlayer）
- **文案**：播放全部 / 收藏 / 下载 / 排序
- **交互**：
  - 点曲目 → 播放该曲目，队列替换为本歌单
  - 点 ⋯ → 弹出曲目操作 Sheet
  - 点收藏 → 心形填充动画
  - 点播放全部 → 从第一首开始播放

## P06 · 搜索 Search

- **布局**：搜索框 + 默认内容
- **未输入状态模块**：
  1. **SearchInputBar** 顶部，圆角 12dp，placeholder "搜索歌曲、歌单、歌手"
  2. **搜索历史** SectionHeader "搜索历史" + 清空图标
     - 标签云 chip，最多 10 个
  3. **热搜榜** SectionHeader "热搜榜"
     - Top 10 列表，序号 1-3 品牌色，4+ 灰色
     - 右侧附 "热" "新" 徽章
- **输入后状态**：
  - 实时展示搜索建议（下拉，最多 5 条）
  - 点建议或回车 → SearchResult
- **空状态**：插画 + "暂无搜索结果" + 推荐热搜

## P08 · 播放页 Player（核心）

- **布局**：全屏覆盖，从 MiniPlayer 上滑展开
- **背景**：当前曲目封面虚化 60px + 渐变遮罩 `brand.gradient` 30%
- **模块**（自上而下）：
  1. **顶部操作行** `[↓ 下滑收起] [正在播放 caption 居中] [⋮ 更多]`
  2. **PlayerCover** 封面
     - 居中，最大 320dp，圆角 28dp
     - 共享元素从 MiniPlayer 封面过渡
  3. **PlayerMeta** 歌曲信息
     - 歌名 display 28sp 600
     - 下方歌手 · 专辑 title3 灰，可点
  4. **PlayerProgress** 进度条
     - `[00:32] ━━●━━━━━━ [03:45]`
     - 4dp 高，已播渐变，未播灰
     - 拖动时显示气泡时间
  5. **PlayerControls** 主控制行
     - `[🔀] [⏮] [▶ 64dp 渐变] [⏭] [🔁]` 等分
  6. **PlayerActions** 次操作行
     - `[♥] [⬇] [💬] [≡队列] [⋮]` 等分
- **文案**：正在播放 / 评论数 / 队列
- **交互**：
  - 下滑 / 点 ↓ → 收回为 MiniPlayer
  - 点封面 → 切换黑胶模式（圆形旋转）
  - 拖动进度条 → 跳转播放位置
  - 点 ♥ → 收藏，心形填充动画 + 微震动
  - 点队列 → QueueSheet 半屏弹窗
  - 点 ⋯ → 曲目操作 Sheet

## P11 · 设置 Settings

- **布局**：分组列表
- **模块**：
  1. **TopAppBar** "设置" + 左返回
  2. **分组：外观**
     - `ThemeSwitcher` 主题切换（跟随系统 / 白昼 / 黑夜）+ 缩略图预览
  3. **分组：播放**
     - 自动播放下一首（开关）
     - 播放音质（值：标准 / 高品 / 无损）→ 跳转选择
     - 定时关闭（值：关闭 / 30分钟 / 60分钟）→ 跳转选择
  4. **分组：下载**
     - 仅 WiFi 下载（开关）
     - 下载路径（值：/storage/Music/TideTune）
  5. **分组：关于**
     - 版本（值：v1.0.0）
     - 用户协议 → 跳转
     - 隐私政策 → 跳转
- **交互**：
  - 切换主题 → 240ms 色值过渡，无需重启
  - 点带箭头项 → 跳转子页或系统页

## 全局浮层

### F01 · MiniPlayerBar 迷你播放条

- **位置**：底部 Tab 栏之上，距 8dp
- **结构**：圆角 16dp 卡片，高 56dp
  - 左封面 40dp 圆角 8dp
  - 中歌名 / 歌手 + 4dp 进度条
  - 右 ▶ ⏭
- **状态**：播放中 ▶ / 暂停 ⏸ / 加载 spinner
- **交互**：
  - 点击条体 → Player 全屏展开
  - 点 ▶ → 播放/暂停
  - 点 ⏭ → 下一首
- **出现动效**：从底部上滑 280ms

### F02 · QueueSheet 播放队列

- **位置**：从 Player 上滑半屏弹窗
- **结构**：磨砂背景，圆角顶部 28dp
  - 顶部 "播放队列 (23)" + 清空图标
  - 当前播放行高亮（品牌色歌名 + 跳动音波）
  - 曲目列表 TrackRow，左拖柄可排序
- **交互**：
  - 点曲目 → 切换播放
  - 长按拖动 → 排序
  - 左滑 → 从队列移除
  - 下滑 / 点遮罩 → 关闭

### F03 · 曲目操作 Sheet（通用）

- **触发**：点 TrackRow 右侧 ⋯
- **结构**：磨砂底部弹窗
  - 顶部曲目信息卡（封面 + 歌名 + 歌手）
  - 操作列表：`[♥ 收藏] [⬇ 下载] [➕ 添加到歌单] [💬 评论] [🔗 分享] [ℹ 歌曲信息] [🗑 删除]`
- **交互**：点任一项执行后关闭
