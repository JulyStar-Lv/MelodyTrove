# ④ 多端差异化适配规则

> 同一套设计 Token，三端各自落地；差异集中在导航、弹窗、手势、断点。

## 4.1 总原则

| 维度 | iOS | Android | Desktop |
| --- | --- | --- | --- |
| 设计基线 | iOS HIG | Material 3 | 各平台原生 |
| 导航 | 底部 Tab + 系统返回手势 | 底部 Tab + 系统返回键 | 左侧栏 + 顶部窗口控件 |
| 圆角 | 偏大（28dp 弹窗常态） | 跟随 M3（16-28dp） | 偏小（12-16dp） |
| 触感 | 长按菜单、3D Touch | 长按菜单 | 右键菜单 |
| 安全区 | notch + home indicator | 状态栏 + 手势条 | 无（窗口可控） |

## 4.2 移动端通用规则（iOS / Android 共享）

- 屏幕宽度 360-428dp 区间一致；> 600dp 进入平板布局
- 底部 Tab 栏 56dp 高 + 安全区底部内边距
- 顶部状态栏透传，内容从安全区顶部开始
- 弹窗从底部上滑，遮罩点击关闭
- 滑动手势：左滑返回（iOS）/ 系统返回键（Android）

## 4.3 iOS 差异化

### 4.3.1 导航栏
- 顶部 `TopAppBar` 字号 17sp 600（iOS Large Title 可选，本设计不用）
- 返回按钮：左箭头 `ic-back-line` + 无文字（遵循 HIG）
- 滚动后顶栏磨砂化（`UIVisualEffectView` 风格）

### 4.3.2 弹窗
- 用 `UISheetPresentationController` 风格，顶部 28dp 圆角，可下拉关闭
- 半屏弹窗顶部附 4×36dp 灰色拖钮（可选，本设计用磨砂 + 内容卡片替代）

### 4.3.3 按钮
- 主按钮：胶囊形（radius.full），高度 48dp，渐变填充，白字
- 次按钮：胶囊形，1px 品牌色边，品牌色字
- 文字按钮：仅品牌色文字，无背景

### 4.3.4 手势
- 左滑返回：所有 Push 页面支持
- 长按曲目：弹出操作 Sheet（收藏/下载/分享/添加到歌单）
- 下滑 Player：收回为 MiniPlayer

### 4.3.5 安全区
- 顶部：`safeAreaInsets.top`（notch 设备 44dp+，无 notch 20dp）
- 底部：`safeAreaInsets.bottom`（home indicator 34dp）

## 4.4 Android 差异化

### 4.4.1 导航栏
- 顶部 `TopAppBar` 字号 18sp 500（Material 风格）
- 返回按钮：左箭头 + 可选"返回"文字（默认无文字）
- 滚动后顶栏 elevation 4dp 阴影（替代磨砂，因 Android 磨砂性能差）

### 4.4.2 弹窗
- 用 `ModalBottomSheet` M3 组件，顶部 28dp 圆角，下拉关闭
- 不附拖钮（M3 默认无拖钮，靠边缘拖动）

### 4.4.3 按钮
- 主按钮：M3 FilledButton，高度 48dp，渐变填充（自定义，M3 默认单色，本设计允许渐变）
- 次按钮：M3 OutlinedButton，1px 边
- 文字按钮：M3 TextButton

### 4.4.4 手势
- 系统返回键：所有页面支持（预测性返回手势 Android 14+）
- 长按曲目：弹出 M3 DropdownMenu 或 BottomSheet
- 下滑 Player：收回为 MiniPlayer

### 4.4.5 安全区
- 顶部：状态栏 24dp（透明，内容透传）
- 底部：手势导航条 16dp（透传）；3 按钮导航 48dp（不透传）

### 4.4.6 Android 特有
- 支持桌面小组件（4×1 MiniPlayer、4×2 最近播放）
- 支持通知栏播放控件（系统 MediaStyle）

## 4.5 Desktop 差异化

### 4.5.1 整体布局
- 左侧栏 240dp 宽，承载 Tab + 我的歌单树
- 顶部 56dp 标题栏（窗口控件 macOS 左 / Windows 右）
- 右侧主内容区，最大宽 1200dp，最小 800dp
- 右下角 MiniPlayer 常驻

```
┌─────┬──────────────────────────────┬──────┐
│ 侧栏 │         主内容区              │ 可选 │
│     │                              │ 详情 │
│     │                              │ 侧栏 │
│     ├──────────────────────────────┤      │
│     │  MiniPlayer 56dp             │      │
└─────┴──────────────────────────────┴──────┘
```

### 4.5.2 导航
- 侧栏顶部：Logo + 搜索框（替代移动端搜索 Tab）
- 侧栏中部：导航项 `[首页] [歌单] [榜单] [本地] [我的]`，选中项左侧 3dp 品牌色指示条
- 侧栏底部：用户头像 + 设置

### 4.5.3 弹窗
- 用窗口内 Dialog，居中显示，圆角 12dp（比移动端小）
- 不用底部 Sheet（桌面无底部概念）

### 4.5.4 按钮
- 主按钮：高度 36dp（比移动端 48dp 矮），圆角 8dp
- 文字按钮：鼠标悬停显示 4dp 品牌色背景

### 4.5.5 交互
- 鼠标悬停：列表行、卡片显示 hover 态（背景 `bg.elevated`）
- 右键：曲目右键菜单（替代长按）
- 键盘：空格播放/暂停，←→ 上一首/下一首，⌘F 搜索，⌘W 关闭
- 双击曲目：直接播放

### 4.5.6 窗口
- 最小窗口：800×600
- 默认窗口：1280×800
- 全屏：F11

## 4.6 平板差异化（移动端 > 600dp）

- 底部 Tab 栏改为左侧栏（同 Desktop 但更窄 200dp）
- 歌单广场 2 列 → 3 列
- 歌单详情页可用双栏（左封面右列表）
- Player 不全屏，改为右侧抽屉或居中卡片

## 4.7 主题切换适配

| 维度 | iOS | Android | Desktop |
| --- | --- | --- | --- |
| 跟随系统 | `UIColor.userInterfaceStyle` | `NightMode` 系统设置 | 系统外观（macOS）/ 不支持（Windows） |
| 切换时机 | 即时，无需重启 | 即时，无需重启 | 即时 |
| 切换动效 | 240ms 色值过渡 | 240ms 色值过渡 | 240ms 色值过渡 |

## 4.8 无障碍（A11y）

- 所有图标附 `contentDescription` / `accessibilityLabel`
- 文字对比度 ≥ 4.5:1（已满足，主文字对比度 12:1）
- 支持系统字体缩放（移动端 SP 字号自动跟随）
- 播放键最小可点击区域 48×48dp
- 支持屏幕阅读器朗读曲目信息（歌名 + 歌手 + 时长）
