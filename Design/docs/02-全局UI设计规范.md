## 2.5 阴影系统

### 2.5.1 白主题（用阴影）

| Token | 阴影 | 用途 |
| --- | --- | --- |
| `shadow.0` | 无 | 普通卡片（用 1px `#EFEFF2` 边替代） |
| `shadow.1` | `0 1px 2px rgba(0,0,0,0.04)` | 悬浮卡片 |
| `shadow.2` | `0 4px 12px rgba(0,0,0,0.06)` | 浮层、MiniPlayer |
| `shadow.3` | `0 12px 32px rgba(46,124,246,0.20)` | 渐变播放键专属光晕 |

### 2.5.2 夜主题（用边 + 内发光，不用阴影）

| Token | 实现 | 用途 |
| --- | --- | --- |
| `shadowDark.0` | `1px solid #1F1F28` | 普通卡片边 |
| `shadowDark.1` | `1px solid #2A2A35` | 悬浮卡片 |
| `shadowDark.2` | `1px solid #2A2A35` + 内发光 `0 0 0 1px rgba(91,155,245,0.10)` | 浮层 |
| `shadowDark.3` | 内发光 `0 0 24px rgba(108,92,231,0.30)` | 渐变播放键光晕 |

> 夜主题禁用黑色阴影（在黑底上无意义），改用边线 + 品牌色微内发光营造层级。

## 2.6 图标规范

- **网格**：24×24dp（设计稿），输出 SVG + PNG@1x/@2x/@3x
- **风格**：线性（默认）/ 填充（选中态），统一 2px 描边
- **线帽**：圆角（round cap / round join）
- **命名**：`ic-{name}-{line|fill}`，如 `ic-play-fill`、`ic-search-line`
- **尺寸用法**：
  - 20dp：Tab 栏、行内图标
  - 24dp：导航栏、操作行
  - 28dp：播放页大图标
  - 32dp：播放键图标

### 核心图标清单（共 24 个）

| 类别 | 图标 |
| --- | --- |
| 播放控制 | play / pause / next / prev / shuffle / repeat / repeat-one |
| 导航 | home / playlist / ranking / search / mine |
| 操作 | heart / heart-fill / download / share / more / add / queue |
| 功能 | back / close / theme / settings / scan / folder |

## 2.7 动效规范

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| Tab 切换 | 180ms | `ease-out` | 仅内容淡入，无位移 |
| 卡片点击 | 120ms | `ease-out` | 缩放 0.98 → 1.0 |
| 弹窗进入 | 280ms | `cubic-bezier(0.32,0.72,0,1)` | 从底部上滑 + 遮罩淡入 |
| Player 展开 | 380ms | `cubic-bezier(0.32,0.72,0,1)` | MiniPlayer → 全屏，封面放大 |
| 播放键按下 | 100ms | `ease-out` | 缩放 0.92 → 1.0，渐变微闪 |
| 进度条拖动 | 实时 | — | 跟手，无延迟 |
| 主题切换 | 240ms | `ease-in-out` | 整页色值过渡，无突兀 |
| 黑胶旋转 | 12s/圈 | `linear` 无限循环 | 播放页封面可选黑胶模式 |

## 2.8 安全区与栅格

- **移动端页面边距**：左右 16dp
- **iOS 安全区**：顶部 notch + 底部 home indicator 各留系统安全区
- **Android**：状态栏 24dp、导航栏 48dp（手势条 16dp）
- **Desktop**：内容区最大宽 1200dp 居中，左右各留 32dp
- **卡片网格**：移动端 2 列（歌单广场），平板 3-4 列，Desktop 5-6 列（响应式）

### Light · 白昼

```
┌─────────────────────────────────────────────────┐
│ 背景 #FFFFFF                卡片 #F7F8FA          │
│                                                 │
│ 主文字 #1A1A1F  ━━━━━━                           │
│ 次文字 #6B6B75  ━━━━━━                           │
│ 弱文字 #9A9AA3  ━━━━━━                           │
│                                                 │
│ 品牌色 ■ #2E7CF6  →  ■ #6C5CE7  (渐变)           │
│                                                 │
│ 分割线 ──────────── #EFEFF2                       │
│                                                 │
│ 渐变播放键 ▶  [■■■■]  阴影 0 12 32 / 20% 蓝       │
└─────────────────────────────────────────────────┘
```

- 整体感受：清爽、克制、留白充足
- 卡片用 1px `#EFEFF2` 边替代阴影（shadow.0），保持扁平
- 仅播放键、悬浮浮层使用阴影
- 渐变是唯一的"色彩高光"

│                                                 │
│ 主文字 #F5F5F7  ━━━━━━                           │

- 渐变在暗背景上更显通透

### 切换规则

- 默认：跟随系统
- 切换动效：240ms `ease-in-out` 整页色值过渡
- 不需重启 App
- 持久化到本地，下次启动恢复
