# TideTune 潮音 · 设计交付索引

> 全平台简约流媒体音乐 App · Android / iOS / Desktop

## 0.1 产品一句话定位

**TideTune（潮音）** —— 一款以"减法"为美学的跨端流媒体音乐 App，让音乐回归聆听本身，用流体视觉与克制交互承载每一次播放。

## 0.2 设计理念（Design Principles）

| 原则 | 含义 | 落地表现 |
| --- | --- | --- |
| **极简克制** | 去掉一切非必要装饰，让音乐成为主角 | 大留白、单色品牌色、弱化分割线 |
| **流体呼吸** | 用渐变与动效营造潮汐流动感 | 渐变播放键、磨砂弹窗、卡片轻浮动效 |
| **双主题无感** | 白昼清爽、黑夜沉浸，切换无突兀 | 同 token 体系，仅色值映射不同 |
| **跨端一致** | 视觉语言一致，交互尊重平台习惯 | 组件统一，导航/弹窗/手势按平台规范 |
| **内容优先** | 封面与标题永远是焦点 | 图大字精，控件低饱和、不抢戏 |
