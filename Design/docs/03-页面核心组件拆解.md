# ③ 各页面核心组件拆解

> 统一格式：组件名 · 用途 · 结构 · 状态 · Props（尺寸/颜色/文案）

## 3.1 全局通用组件

### 3.1.1 `TopAppBar` 顶部导航栏

- **用途**：页面顶部，承载标题 + 左返回 + 右操作
- **结构**：`[左图标] [标题居中/左对齐] [右图标1] [右图标2]`
- **状态**：默认 / 滚动后磨砂化（白主题 80% 白 + 模糊 20px）
- **Props**：
  - `title: String`
  - `showBack: Boolean`（默认 false）
  - `actions: List<IconAction>`（最多 2 个）
  - `scrolled: Boolean`（控制磨砂态）

### 3.1.2 `BottomTabBar` 底部 Tab 栏

- **结构**：5 个 `TabItem` 等分排列，文字 12sp，图标 20dp
- **状态**：选中（图标 fill + 品牌色）/ 未选中（图标 line + 灰）
- **Props**：`tabs: List<TabItem>`、`current: Int`、`onSelect`

### 3.1.3 `MiniPlayerBar` 迷你播放条（核心）

- **位置**：底部 Tab 栏之上，常驻浮层
- **结构**：
  ```
  ┌─────────────────────────────────────────┐
  │ ▢封面  歌名 / 歌手        ▶  ⏭  ▢操作  │
  │         ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬  （进度） │
  └─────────────────────────────────────────┘
  ```
- **状态**：播放中（▶）/ 暂停（⏸）/ 加载中（转圈替代 ▶）
- **Props**：`track: Track`、`isPlaying`、`progress: Float(0-1)`
- **交互**：点击条体 → 展开 Player；点 ▶ 切换播放；点 ⏭ 下一首
- **样式**：圆角 16dp，shadow.2，距 Tab 栏 8dp

### 3.1.4 `GradientPlayButton` 渐变播放键

- **结构**：圆形 56dp，渐变填充 `brand.gradient`，中心 24dp 白色 play 图标
- **状态**：默认 / 按下（scale 0.92）/ 加载（替换为 24dp spinner）
- **特殊**：外圈可附 28dp 进度环（MiniPlayer 不需要，Player 需要）
- **Props**：`size: 48|56|64`、`progress: Float?`、`isPlaying`

### 3.1.5 `FrostedSheet` 磨砂弹窗

- **用途**：QueueSheet、操作菜单、分享等
- **结构**：从底部上滑，圆角顶部 28dp，背景 `bg.elevated` + 模糊 24px
- **Props**：`show: Boolean`、`height: Wrap|Half|Full`、`onDismiss`

## 3.2 首页 Home 组件

### 3.2.1 `HomeHeader` 首页头部

- **结构**：左 Logo "TideTunes" + 右主题切换图标
- **样式**：不用 TopAppBar，自定义大标题（title1 字号 22sp，600）

### 3.2.2 `BannerCarousel` 轮播横幅

- **结构**：横向滑动卡片，每张 16:9，圆角 20dp
- **Props**：`items: List<Banner>`、`autoPlay: 4s`
- **指示器**：底部 4dp 圆点，当前 16dp 品牌色，其余 4dp 灰

### 3.2.3 `SectionHeader` 区块标题

- **结构**：`[标题 title2] ──────── [更多 →]`
- **Props**：`title`、`showMore`

### 3.2.4 `PlaylistCardGrid` 歌单卡（2 列网格）

- **结构**：
  ```
  ┌────────────┐
  │  封面 1:1   │  ← 圆角 20dp，shadow.1
  ├────────────┤
  │ 歌单名 2 行 │  ← body 14sp，2 行截断
  │ ▢播放数 12sp│  ← caption 灰
  └────────────┘
  ```
- **Props**：`playlist: Playlist`、`width: 164|200`

### 3.2.5 `TrackRow` 曲目行（核心，多处复用）

- **结构**：
  ```
  ┌───────────────────────────────────────┐
  │ ▢封面  歌名             3:24  ▶  ⋯   │
  │  40dp  歌手 · 专辑                  │
  └───────────────────────────────────────┘
  ```
- **状态**：默认 / 播放中（歌名变品牌色，附 16dp 跳动音波图标）/ 长按
- **Props**：`track`、`isPlaying`、`showIndex: Boolean`（排行榜用数字替代封面）

### 3.2.6 `DailyRecommendCard` 每日推荐卡（首页专属）

- **结构**：横向卡片，左封面 80dp + 右文案 + 大渐变播放键
- **日期**：右上角显示 "06.24" 日期徽章

## 3.3 歌单广场 PlaylistSquare 组件

### 3.3.1 `CategoryTabs` 分类标签条

- **结构**：横向滚动 chip，选中态填充品牌色 10% 背景 + 品牌色文字
- **Props**：`categories: List<String>`、`current`

### 3.3.2 `PlaylistCardGrid` 复用 3.2.4，列数响应式（2/3/4）

## 3.4 歌单详情 PlaylistDetail 组件

### 3.4.1 `PlaylistHero` 歌单头部英雄区

- **结构**：
  ```
  ┌─────────────────────────────┐
  │ ▢封面 120dp   歌单名 title1  │
  │              创建者 · 头像   │
  │              标签 chips       │
  │              ▢播放全部 ▢收藏 │
  └─────────────────────────────┘
  ```
- **背景**：封面虚化 30px 模糊 + 70% 暗化遮罩，营造沉浸
- **按钮**：播放全部 = `GradientPlayButton` 56dp + "播放全部" 文字

### 3.4.2 `TrackList` 曲目列表

- **结构**：`TrackRow` × N，无卡片包裹，行高 56dp
- **顶部**：`[播放全部] [下载] [排序]` 工具行

## 3.5 排行榜 Ranking 组件

### 3.5.1 `RankingTabBar` 榜单切换条

- **结构**：顶部 4 个 Tab（飙升 / 新歌 / 热歌 / 原创），下划线 2dp 品牌色

### 3.5.2 `RankingPodium` 三甲展示

- **结构**：前三名特殊展示，2 号 1 号 3 号阶梯排列，封面更大，序号用渐变文字

### 3.5.3 `RankingList` 4 名之后列表

- **复用** `TrackRow`，`showIndex=true`，序号 4 起为灰色数字

## 3.6 搜索 Search 组件

### 3.6.1 `SearchInputBar` 搜索输入框

- **结构**：`[🔍 输入框 圆角 12dp] [取消]`
- **状态**：未聚焦（灰底）/ 聚焦（白底 + 品牌色光标）/ 有内容（右侧 × 清空）

### 3.6.2 `SearchHistory` 搜索历史

- **结构**：标签云（chip），最近 10 条，右上"清空"图标

### 3.6.3 `HotSearchList` 热搜榜

- **结构**：Top 10 列表，序号 1-3 用品牌色，4 起灰色，右侧附"热/新"小徽章

### 3.6.4 `SearchResultTabs` 搜索结果 Tab

- **结构**：`综合 / 歌曲 / 歌单 / 歌手 / 专辑`，下划线切换

## 3.7 播放页 Player 组件（核心）

### 3.7.1 `PlayerBackground` 播放页背景

- **实现**：当前曲目封面虚化 60px + 渐变遮罩 `brand.gradient` 30% + 整体亮度根据主题调整
- **动效**：切换曲目时背景渐变过渡 600ms

### 3.7.2 `PlayerCover` 播放页封面

- **结构**：正方形封面，圆角 28dp，居中，最大 320dp
- **动效**：展开时从 MiniPlayer 封面 40dp 平滑放大到 320dp（共享元素过渡）
- **可选模式**：黑胶模式（圆形封面 + 中心圆孔 + 12s 旋转）

### 3.7.3 `PlayerMeta` 歌曲信息

- **结构**：`[歌名 display] [歌手 · 专辑 title3 灰]` + 右侧 ⋯
- **交互**：点歌手跳转 ArtistDetail

### 3.7.4 `PlayerProgress` 进度条

- **结构**：`[当前时间] ━━●━━━━ [总时长]`
- **样式**：4dp 高，已播 `brand.gradient`，未播灰，拖钮 12dp 白色圆
- **交互**：拖动时显示气泡时间提示

### 3.7.5 `PlayerControls` 主控制行

- **结构**：`[🔀] [⏮] [▶ 64dp] [⏭] [🔁]` 等分排列
- **中央**：`GradientPlayButton` 64dp

### 3.7.6 `PlayerActions` 次操作行

- **结构**：`[♥] [⬇] [💬] [≡队列] [⋮]` 等分
- **状态**：♥ 已收藏为 `color.like` 填充

## 3.8 本地音乐 LocalMusic 组件

### 3.8.1 `LocalScanBanner` 扫描引导条

- **结构**：插画 + "扫描本地音乐" + 渐变按钮

### 3.8.2 `LocalFolderTabs` 文件夹切换

- **结构**：`[全部] [按歌手] [按专辑] [按文件夹]` 顶部切换

### 3.8.3 `LocalTrackList` 复用 TrackRow + 右侧"更多"含"删除"

## 3.9 我的 Mine 组件

### 3.9.1 `ProfileCard` 个人卡

- **结构**：头像 64dp + 昵称 title1 + 等级徽章 + "登录"按钮（未登录态）

### 3.9.2 `QuickEntryGrid` 快捷入口

- **结构**：2×2 网格，`[最近播放] [我的收藏] [本地音乐] [我的下载]`，每格图标 + 文字 + 数字

### 3.9.3 `MyPlaylistSection` 我创建/收藏的歌单

- **结构**：横向 Tab `[我创建] [我收藏]` + 列表

## 3.10 设置 Settings 组件

### 3.10.1 `SettingGroup` 设置分组

- **结构**：分组标题 caption 灰 + 圆角卡片包裹的 `SettingRow` 列表

### 3.10.2 `SettingRow` 设置行

- **结构**：`[左图标 32dp 圆角 8dp 浅底] [标题] [副标题/开关/箭头]`
- **变体**：`toggle`（开关）/ `value`（显示值）/ `arrow`（跳转）

### 3.10.3 `ThemeSwitcher` 主题切换

- **结构**：三选项 `[跟随系统] [白昼] [黑夜]`，当前项品牌色边框 + 勾选
- **预览**：每项附 64×40dp 缩略图
