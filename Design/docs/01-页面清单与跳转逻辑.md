# ① 产品页面清单与跳转逻辑

## 1.1 页面总览

TideTune 共 **15 个核心页面** + **2 个全局浮层**，按层级分为 4 组。

| 分组 | 页面代号 | 页面名称 | 类型 | 备注 |
| --- | --- | --- | --- | --- |
| **启动** | `Splash` | 启动页 | 全屏 | 品牌动效，自动进入 |
| **主 Tab（5）** | `Home` | 首页推荐 | Tab | 默认首屏 |
| | `PlaylistSquare` | 歌单广场 | Tab | 分类筛选 |
| | `Ranking` | 排行榜 | Tab | 多榜切换 |
| | `Search` | 搜索 | Tab | 默认焦点 |
| | `Mine` | 我的 | Tab | 个人中心 |
| **二级详情（5）** | `PlaylistDetail` | 歌单详情 | Push | 含曲目列表 |
| | `ArtistDetail` | 歌手详情 | Push | 作品+MV+简介 |
| | `AlbumDetail` | 专辑详情 | Push | 可选页，复用歌单详情结构 |
| | `LocalMusic` | 本地音乐 | Push | 扫描+列表 |
| | `Settings` | 设置 | Push | 含主题切换 |
| **全屏层级（2）** | `Player` | 播放页 | 全屏覆盖 | 从底部上滑展开 |
| | `SearchResult` | 搜索结果 | Push | 多 Tab 结果 |
| **全局浮层（2）** | `MiniPlayerBar` | 迷你播放条 | 浮层 | 常驻 Tab 之上 |
| | `QueueSheet` | 播放队列 | 半屏弹窗 | 磨砂 |

## 1.2 底部 Tab 结构

```
┌─────────────────────────────────────────────┐
│              内容区（滚动）                  │
├─────────────────────────────────────────────┤
│ ▢ MiniPlayerBar（有播放时出现，56dp 高）     │
├──────┬──────┬──────┬──────┬──────┬──────────┤
│ 首页 │ 歌单 │ 榜单 │ 搜索 │ 我的 │  ← 5 Tab │
└──────┴──────┴──────┴──────┴──────┘
```

- Tab 数量：5（移动端），Desktop 折叠为左侧侧栏
- 当前 Tab 图标填充态 + 品牌色，其余为线性灰
- Tab 切换无横向滑动，点击直跳

## 1.3 页面跳转逻辑图（文字版）

### 1.3.1 主流程

```
[Splash]
   │ (1.2s 自动)
   ▼
[Home] ◄──默认首屏
   │
   ├─(Tab)─► [PlaylistSquare] ──(点歌单)──► [PlaylistDetail] ──(点歌手头像)──► [ArtistDetail]
   │                                              │
   │                                              ├─(点曲目)──► 触发播放 → [MiniPlayerBar]
   │                                              └─(更多)──► [QueueSheet]
   │
   ├─(Tab)─► [Ranking] ──(点榜)──► [PlaylistDetail]
   │
   ├─(Tab)─► [Search] ──(输入)──► [SearchResult] ──(点歌单/歌手/专辑)──► 对应 Detail
   │
   └─(Tab)─► [Mine] ──(本地音乐)──► [LocalMusic]
                    ──(设置)──────► [Settings] ──(主题)──► 切换白/夜/跟随系统
```

### 1.3.2 播放流程（核心动线）

```
任意曲目点击
   │
   ▼
[MiniPlayerBar] 出现（底部，Tab 之上，56dp）
   │
   ├─(点击条体)──► [Player] 全屏播放页（从底部上滑展开，背景磨砂模糊）
   │                  │
   │                  ├─(下滑/返回)──► 收回为 MiniPlayerBar
   │                  ├─(队列按钮)──► [QueueSheet] 半屏弹窗
   │                  └─(更多按钮)──► 曲目操作 Sheet（收藏/下载/分享/评论）
   │
   ├─(播放/暂停)──► 切换播放状态（渐变键变静）
   └─(下一首)────► 切换曲目
```

### 1.3.3 返回逻辑

| 当前页 | 返回目标 | 触发方式 |
| --- | --- | --- |
| `Player` | 上一页（保持 MiniPlayerBar） | 下滑手势 / 系统返回 |
| `QueueSheet` | `Player` | 点遮罩 / 下滑 |
| `PlaylistDetail` 等详情页 | 来源 Tab 页 | 系统返回 / 左滑(iOS) |
| `SearchResult` | `Search` | 清空搜索框 / 返回 |
| 主 Tab 之间 | 不返回，状态各自保留 | — |
| 主 Tab 再按返回 | 退出 App | 系统返回键 |

## 1.4 页面状态说明

- **空状态**：歌单为空、无搜索历史、本地音乐未扫描时，展示插画 + 引导文案 + 主按钮
- **加载态**：骨架屏（封面灰块 + 文字灰条），不使用转圈
- **错误态**：插画 + 错误文案 + "重试"按钮
- **离线态**：顶部出现 24dp 黄色提示条 "当前离线，仅可播放已下载内容"

## 1.5 页面优先级（开发排序建议）

| 优先级 | 页面 | 理由 |
| --- | --- | --- |
| P0 | Home / Player / MiniPlayerBar / PlaylistDetail | 核心听歌闭环 |
| P1 | Search / SearchResult / Ranking / Mine | 探索与个人中心 |
| P2 | PlaylistSquare / ArtistDetail / LocalMusic | 内容扩展 |
| P3 | Settings / QueueSheet / Splash | 体验完善 |
