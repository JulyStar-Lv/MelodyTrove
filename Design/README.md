## 核心设计决策摘要

| 维度 | 决策 |
| --- | --- |
| 品牌色 | 海潮蓝 `#2E7CF6` → 暮光紫 `#6C5CE7` 渐变 |
| 白主题 | 纯白 `#FFFFFF` + 抬升 `#F7F8FA`，主文字 `#1A1A1F` |
| 夜主题 | `#0B0B0F`（非纯黑）+ 抬升 `#16161D`，禁用黑色阴影改用边线 + 内发光 |
| 字体 | 系统默认（SF Pro / Roboto / system-ui），不打包自定义字体 |
| 间距 | 8pt 网格，4 的倍数 |
| 圆角 | 8 / 12 / 16 / 20 / 28 / full 六档 |
| 播放键 | 圆形渐变，56dp / 64dp，唯一品牌高光 |
| 弹窗 | 磨砂底部 Sheet，圆角顶部 28dp |
| 主题切换 | 240ms 色值过渡，无需重启 |
