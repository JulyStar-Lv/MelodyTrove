# 主题样式参考 · Light & Dark

## Light · 白昼

```
┌─────────────────────────────────────────────────┐
│ 背景 #FFFFFF                卡片 #F7F8FA          │
│                                                 │
│ 主文字 #1A1A1F  ━━━━━━                           │
│ 次文字 #6B6B75  ━━━━━━                           │
│ 弱文字 #9A9AA3  ━━━━━━                           │
│                                                 │
│ 品牌色 ■ #2E7CF6  →  ■ #6C5CE7  (渐变)           │
│                                                 │
│ 分割线 ──────────── #EFEFF2                       │
│                                                 │
│ 渐变播放键 ▶  [■■■■]  阴影 0 12 32 / 20% 蓝       │
└─────────────────────────────────────────────────┘
```

- 整体感受：清爽、克制、留白充足
- 卡片用 1px `#EFEFF2` 边替代阴影（shadow.0），保持扁平
- 仅播放键、悬浮浮层使用阴影
- 渐变是唯一的"色彩高光"

## Dark · 黑夜

```
┌─────────────────────────────────────────────────┐
│ 背景 #0B0B0F                卡片 #16161D          │
│                                                 │
│ 主文字 #F5F5F7  ━━━━━━                           │
│ 次文字 #9A9AA3  ━━━━━━                           │
│ 弱文字 #6B6B75  ━━━━━━                           │
│                                                 │
│ 品牌色 ■ #2E7CF6  →  ■ #6C5CE7  (渐变)           │
│                                                 │
│ 分割线 ──────────── #1F1F28                       │
│                                                 │
│ 渐变播放键 ▶  [■■■■]  内发光 0 0 24 / 30% 紫      │
└─────────────────────────────────────────────────┘
```

- 整体感受：沉浸、深邃、有"潮汐深度感"
- 不用纯黑 `#000`，避免 OLED 死黑断层
- 禁用黑色阴影（在黑底无意义），用 1px 边 + 品牌色微内发光
- 渐变在暗背景上更显通透

## 双主题对照表

| Token | Light | Dark |
| --- | --- | --- |
| bg.base | `#FFFFFF` | `#0B0B0F` |
| bg.elevated | `#F7F8FA` | `#16161D` |
| text.primary | `#1A1A1F` | `#F5F5F7` |
| text.secondary | `#6B6B75` | `#9A9AA3` |
| text.tertiary | `#9A9AA3` | `#6B6B75` |
| divider | `#EFEFF2` | `#1F1F28` |
| 卡片层级 | 阴影 0 1 2 | 边 0 1 2 |
| 播放键光晕 | 蓝色阴影 20% | 紫色内发光 30% |

## 切换规则

- 默认：跟随系统
- 切换动效：240ms `ease-in-out` 整页色值过渡
- 不需重启 App
- 持久化到本地，下次启动恢复
