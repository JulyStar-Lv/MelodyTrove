- 更新 PDS 文档到 v4：新增第 10 章"Responsive Multi-Device System"，含 Breakpoint / Navigation Architecture / Mini Player State System / MIUI HyperOS Settings / Device Layout Matrix / 关键约束

### 关键决策
- **7 种设备 × 5 断点 × 4 Mini Player 状态**：完整覆盖从 320dp 到 4K 屏幕的响应式范围
- **Mini Player 共享元素动画**：封面 + 标题在 4 状态间通过 Blur Morph 过渡，是整个系统的核心交互语法
- **MIUI HyperOS 卡片分组**：Settings 5 个独立 CardGroup，每组 16-28dp 圆角 + 柔和阴影 + 内部行分割线
- **导航架构变更**：移除 Playing Tab（5→4），Mini Player 是进入 Now Playing 的唯一入口 — 符合 Apple Music 信息架构
- **断点 5 档命名**：Compact(0-599) / Medium(600-839) / Expanded(840-1279) / Large(1280-1599) / XL(1600+)

### 技术细节
- **batch_edit 操作格式**：JavaScript 函数调用语法（`U("5:830", {layout: "vertical"})`），不是管道分隔
- **gradientStops 必须有 `a` 字段**：否则 fills 应用失败
- **fill_container 需要父级有 auto-layout**（layout: "horizontal"/"vertical"），否则回退为固定尺寸
- **Glassmorphism 实现**：BACKGROUND_BLUR + 半透明白色 fill (opacity: 0.72) + 白色 stroke (opacity: 0.5) + DROP_SHADOW
- **截图保存路径**：必须使用绝对路径，否则 screenshot 文件可能保存到默认位置

## TideTunes DS v5 — Figma Make Alignment

### 用户需求
用户要求把 Figma Make 链接（https://www.figma.com/make/X30WgdPxOW9skIgTUCgk4b/Design-System-for-TideTunes）导入到 Ardot 画布

### 关键发现
1. **Figma Make 是 AI 生成的代码原型**，非 Figma 原生设计文件
   - `editorType: "make"`，REST API 不支持（返回 400 "File type not supported by this endpoint"）
   - 实际是 React + CSS 代码 + iframe 嵌入 Figma
2. **Figma Make 提供了完整设计系统 metadata**（通过 `document.body.innerText` 抓取）：
   - 品牌色 TidePink #FF5B8A + TidePurple #7A6CFF（与 v3/v4 完全一致）
   - 字体 Plus Jakarta Sans + JetBrains Mono（v3/v4 是 Inter，可升级）
   - 圆角 12/20/28/36（v3/v4 是 8/16/24/32，可对齐到 12/20/28/36）
   - 8 个渐变对（v4 已有 3 种，需要补全）
   - 5 个 Music Cards + 12 个 Primitives/Layout/Player 组件
   - 4 个 App Pages + 3 个 DS Docs section
   - Desktop 240px sidebar + Mobile bottom nav + active indicator animation

### Figma Make 抓取技术记录
- **Figma Make 访问限制**：
  - `/v1/files/{key}` → 400 File type not supported
  - `/v1/images/{key}` 无 ids → 返回 2 个节点 PNG URL
  - Playwright headless 拦截（`ERR_CONNECTION_CLOSED` 加载 WASM 失败）
  - 公开 share token `?t=...` 在 headless 下仍被识别为 bot
- **抓取策略**：
  1. Playwright Chromium 抓取 Figma 文档侧栏 + Home 视图主区域截图
  2. `document.body.innerText` 提取完整 AI 生成的 metadata
  3. PNG 节点导出用于图片分析
