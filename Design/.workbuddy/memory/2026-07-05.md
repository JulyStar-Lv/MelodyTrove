# 2026-07-05 · TideTunes Design System v3 升级

## 用户决策
- v1/v2 → v3 范式转变：UI Prompt → 完整 Product Design Specification (PDS)
- 目标：建立可长期维护、支持 Compose Multiplatform + compose-miuix-ui + Android/iOS/Desktop 的设计规范
- 目标级别：Apple HIG / Material Design / HyperOS Design Language 级别

## v3 核心定位
**Apple Music Information Architecture × HyperOS Design Language × Compose Multiplatform Responsive Design System**

## 关键决策点
- **品牌色升级**：#2E7CF6/#6C5CE7 → #FF5B8A（潮汐粉）/#7A6CFF（极光紫），品牌色饱和度提升
- **导航重构**：5 Tab（Home/Playlist/Ranking/Search/Mine）→ 4 Tab（Home/Search/Library/Settings），移除 Now Playing Tab
- **播放器入口**：仅通过 Mini Player 进入（Apple Music 模式）
- **Source 架构**：从设置项提升为一级能力，10+ 来源类型卡片化
- **Library 重组**：扩展为 13 个分类（含 Lossless/Hi-Res/Sources）
- **Settings 风格**：从 Material → HyperOS Grouped Card 风格
- **圆角升级**：8/12/16/20/28/full → 12/18/24/28/36/full，整体更大
- **新增 Token 类别**：Blur（5 档）、Motion（6 种）、Elevation（5 级）、Adaptive Width、Touch Target
- **新增加 Compose 映射**：完整 Figma → Compose 组件 + Token 映射
