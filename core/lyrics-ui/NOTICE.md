# lyrics-ui attribution

This module is a Compose Multiplatform adaptation of the lyric-following and karaoke rendering ideas in:

- https://github.com/cwuom/accompanist-lyrics-ui
- Original project: https://github.com/6xingyv/Accompanist

The adaptation keeps TideTunes free of Android-only APIs while retaining automatic line following,
distance-based focus/blur, translations, click-to-seek, and syllable timing progress. The upstream
project is licensed under Apache License 2.0. See `LICENSE-APACHE-2.0` in this directory.
